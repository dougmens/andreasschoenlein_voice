# Andreas Schönlein Voice

Erste responsive Website-Vorschau für Andreas Schönlein, Radio- und TV-Moderator und Sprecher aus München.

## Website

https://dougmens.github.io/andreasschoenlein_voice/

GitHub Pages veröffentlicht den Inhalt des Hauptverzeichnisses auf `main`. Änderungen an `index.html` werden nach dem GitHub-Pages-Build automatisch übernommen.

## Stand

- Cinematic-Dark-Entwurf mit neun eingebetteten WebP-Motiven
- Responsive Navigation und Filter für die vorbereitete Hörprobenbibliothek
- Studio-Motive sind als KI-Inszenierungen gekennzeichnet
- Keine externen Schriftarten, Analysewerkzeuge oder Medien-Einbettungen
- Hörproben, echte Videoclips, Kontaktmöglichkeit, Impressum und Datenschutzhinweise noch ergänzen
- `noindex,nofollow` bleibt während der Entwurfsphase aktiv (kein Zugriffsschutz)

## Bearbeitung

`index.html` enthält Layout, Bilder, CSS und JavaScript. Die Datei kann direkt im Browser geöffnet oder im Codespace bearbeitet werden. `.nojekyll` stellt die direkte Auslieferung als statische Seite sicher. Eine eigene Domain wird erst nach Registrierung und Bestätigung eingerichtet.
