# SEO-Stand 12.11.2026

Sieben eigenständige Unterseiten, beschreibende URLs, individuelle Titel und Beschreibungen, Canonicals, Social-Metadaten, JSON-LD und verlinkte Seitennavigation. Statisches HTML benötigt kein JavaScript für Inhalte oder Links. Gemeinsame WebP-Dateien, CSS und JavaScript verbessern die Wiederverwendung aus dem Cache. Keine erfundenen Referenzen, Preise oder Studios.

## Vorschau und Indexierung

Alle acht Seiten behalten noindex,follow, bis Impressum und Datenschutzhinweise ergänzt und geprüft sowie Inhalte und Angebotsstatus bestätigt sind. Vorherige Einstellung war noindex,nofollow. Für den regulären Start noindex auf allen Seiten entfernen und sitemap.xml in Google Search Console einreichen. Eine Sitemap garantiert keine Indexierung. Originalhörproben und freigegebene Arbeitsbeispiele ergänzen.

Keine robots.txt im GitHub-Projekt-Unterpfad: Regeln müssen vom Host-Stamm /robots.txt aus bereitgestellt werden. Noindex-Seiten müssen abrufbar bleiben.

Bei Domainwechsel absolute Canonicals, Social-URLs, JSON-LD und sitemap.xml umstellen, GitHub Pages Custom Domain und HTTPS einrichten, Search Console verifizieren und Weiterleitungen prüfen.
